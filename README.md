# 日迹 · 书影音记录

每天花十几秒，把看过的、读过的、玩过的、发生的事记一笔。
不评分、不写长评，只留记录；完成的事情亮一个金色奖杯。

- **九个类目**：游戏 · 影视 · 电影 · 书籍 · 播客 · 音乐 · 活动 · 社交 · 大事件
- **点图标 → 写一句 → 记下**，抽屉里可以直接横滑换类目
- **抽屉可拖动**：点类目时弹出一半；抓住顶部把手向上拖，铺满全屏看长列表；向下拖过了 80px 就收起
- **左右滑动**：今日页左滑去日历、右滑去时间轴；日历里左/右滑切换月份；时间轴右滑回今日
- **深色模式**：默认跟随系统；设置里可以关掉跟随，手动选浅色 / 深色
- **改和删**：在日历的当天明细、或时间轴里，点任意一条就能改文字、切换完成状态或删除
- **奖杯**：只有书籍 / 影视 / 电影 / 播客 / 单机游戏有；点亮后显示「🏆 已读完」这类字样，未点亮时什么都不显示
- **游戏分两层**：单机单次游玩 / 常玩的手游（先选手游，再写今天玩了什么）
- **日历**：月视图看每天记录了哪些、有没有点亮；点某天展开当天明细
- **时间轴**：按日倒序回看全部记录
- **数据**：存在手机浏览器本地，可导出 JSON 备份、导出 CSV 导入多维表

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部界面与逻辑（单文件，无框架、无构建） |
| `manifest.webmanifest` | 让手机能「添加到主屏幕」 |
| `sw.js` | 离线缓存，断网也能打开 |
| `icons/` | 应用图标 |
| `fonts/Jiayou.ttf` | 手写字体「今年也要加油鸭」（约 7MB，必须一起上传） |

## 部署到 GitHub Pages（约 3 分钟）

1. 登录 GitHub，右上角 `+` → **New repository**
2. 仓库名填 `riji`，选 **Public**，不要勾选任何初始化文件，点 **Create repository**
3. 在空仓库页面点 **uploading an existing file**（或 Add file → Upload files）
4. 把 `index.html`、`manifest.webmanifest`、`sw.js`、`icons` 文件夹、`fonts` 文件夹一起拖进去 → **Commit changes**
5. 进入仓库 **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 **main** / **（root）** → **Save**
6. 等 1～2 分钟，访问 `https://你的用户名.github.io/riji/`

> 所有路径都是相对的，放在子目录下也能正常工作。

## 装到手机主屏幕

- **iPhone**：用 **Safari** 打开上面的网址 → 分享按钮 → **添加到主屏幕**
- **Android**：用 **Chrome** 打开 → 右上角菜单 → **添加到主屏幕 / 安装应用**

装好后是全屏无地址栏的，第一次打开过一次之后断网也能用。
（微信内置浏览器不支持安装，需要复制链接到系统浏览器打开。）

## 数据在哪、怎么备份

数据保存在**打开它的那台设备的浏览器**里（localStorage），不上传、不联网、不经过任何服务器。

- **换手机 / 清理浏览器数据前**：设置 → 导出备份，得到 `日迹备份-日期.json`；新设备上设置 → 导入备份
- **想进飞书多维表 / Notion**：设置 → 导出表格，得到 CSV（UTF-8 BOM，Excel 和飞书都能直接读）

列结构：`日期, 星期, 分类, 名称, 详情, 完成, 完成时间`

## 更新版本

改完 `index.html` 后，把 `sw.js` 第一行的 `const VER = "riji-v1"` 改成 `riji-v2`（否则手机可能读到旧缓存），再上传覆盖。

## 常见问题

**字体不是手写体？**
主字体是「今年也要加油鸭」，文件在 `fonts/Jiayou.ttf`（约 7MB），完全自托管，不依赖任何 CDN。因为体积大，页面会先用系统圆体渲染，字体下载完成后自动切换（约几百毫秒到两三秒），所以首屏不会被卡住。部署时必须把 `fonts/` 一起上传，否则会一直显示圆体。

**打不开了 / 一直白屏？**
先联网重新打开一次，让 service worker 更新缓存。

**记录好像不见了？**
多半是访问地址变了（换了域名或端口）。浏览器按「地址」隔离本地数据，旧数据还在原地址下。用固定的 GitHub Pages 域名就不会出现。

**同一个项目跨了好几天（追剧、连载）？**
每次记录是独立的一条，点亮只影响当条。日历里能看到每天分别记了什么。

**想改类目或配色？**
`index.html` 里搜索 `const CATS`，每个类目有这些字段：

| 字段 | 含义 |
| --- | --- |
| `name` | 显示的名字 |
| `tint` | 首页圆形色块的底色（饱和的那个） |
| `soft` | 打开抽屉时的整屏底色（浅一档） |
| `fg` | 该类目的文字/图标色（深色同源，抽屉里的所有文字都会变成它） |
| `sub` | 详情栏的提示文字 |
| `word` | 点亮后的字样，如「已读完」 |
| `trophy` | 是否有奖杯 |

**怎么改默认的手游清单？**
搜索 `DB = { entries:[], games:[` 那一行，改初始数组；也可以直接在设置页里增删。
